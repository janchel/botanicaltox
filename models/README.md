# Trained Models

Place your `.pkl` model files here.

## Naming Convention

```
activity_<name>.pkl    — Activity classifier
toxicity_<name>.pkl    — Toxicity classifier
```

## Starter Models

If you cloned this repo, train your first model:
1. Start the app: `python3 app.py`
2. Go to http://localhost:5000/train
3. Upload `datasets/medchem_training.csv`
4. Train with model name `default`

The model will be saved here automatically.
