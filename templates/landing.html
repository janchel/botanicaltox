Screen plant compounds against a hospital superbug

CRABLOX trains machine-learning models on molecule data. It predicts which compounds may block the enzymes that make carbapenem-resistant Acinetobacter baumannii (CRAB) resistant, flags likely liver toxicity, and ranks what to test in the lab first.

Predict compoundsTrain a model

CRAB is on the WHO’s Priority 1: Critical list. Up to 56% of Philippine A. baumannii isolates resist carbapenems.

How the models are built

Every model follows the same five steps, so results can be repeated and checked.

  1. Describe

    Turn each molecule into numbers: topological indices (Wiener, Zagreb, Balaban) plus physicochemical and ADMET descriptors.

  2. Split by scaffold

    Keep molecules with the same core together, so the test set holds structures the model has not seen.

  3. Train two models

    One Random Forest predicts Class D β-lactamase activity. A second predicts liver toxicity.

  4. Check against chance

    Measure MCC and AUC-ROC, then retrain on shuffled labels to confirm the result is not luck.

  5. Rank

    Combine both scores into one priority score and list the top candidates.

What the study found

CRABLOX screened 260 flavonoids from Philippine medicinal plants. The results point to a shortlist for lab testing.

0.455Activity model MCC, averaged over 20 scaffold-grouped tests (AUC-ROC 0.794)
0.26Liver-toxicity model MCC (AUC-ROC 0.70)
259 of 260compounds sit outside the chemistry the activity model learned from

Read the shortlist as a starting point. No flavonoid scored above the 0.5 activity threshold, and the topological indices added no predictive value. Any candidate needs enzyme assays before it is called an inhibitor.
